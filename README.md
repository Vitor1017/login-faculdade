Automação de Login no Colabora 
🔗 Repositório: Link do GitHub https://github.com/Vitor1017

📌 Descrição
Script Python que automatiza o login no portal Colabora READ (Ambiente Virtual de Aprendizagem) utilizando Selenium WebDriver. O projeto demonstra automação web básica para fins educacionais.

🎯 Objetivo
Demonstrar automação de processos web com Python

Simular login em sistemas acadêmicos

Praticar interação com elementos HTML via Selenium

🛠️ Tecnologias Utilizadas
Python 3 (Linguagem principal)

Selenium WebDriver (Automação web)

ChromeDriver (Navegador controlado)

⚙️ Funcionalidades
✔️ Automação completa do fluxo de login
✔️ Navegação até a página do curso
✔️ Manipulação de elementos HTML (inputs, botões)
✔️ Tratamento básico de exceções
